# Roadmap

Note: keep this document minimal. Each item should state only the bare idea and the intended outcome.

## Post-paste learning

After Cue pastes text into another app, watch for user edits.

If the user corrects what Cue inserted, use that as a feedback signal to improve
future transcription.

## In-process LLM cleanup

Run a small local LLM after transcription to clean up the raw output using
specific instructions.

Turn rough transcription into cleaner, more usable text without leaving the app.
